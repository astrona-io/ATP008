# ATP008 — Kubernetes and Cloud Native Associate (KCNA)

Preparation scaffold: one stage per exam domain, connected through `path.yaml`
to a training series repository. New material is planned, and the course
registration in `astrona-content` stays **draft**.

This exam is part of the current Golden Kubestronaut requirements.

| Stage | Domain | Weight | Series |
| --- | --- | --- | --- |
| STG001 | Kubernetes Fundamentals | 44% | [ATS037](https://github.com/astrona-io/ATS037) |
| STG002 | Container Orchestration | 28% | [ATS038](https://github.com/astrona-io/ATS038) |
| STG003 | Cloud Native Application Delivery | 16% | [ATS039](https://github.com/astrona-io/ATS039) |
| STG004 | Cloud Native Architecture | 12% | [ATS040](https://github.com/astrona-io/ATS040) |

Source: [official KCNA curriculum](https://training.linuxfoundation.org/certification/kubernetes-and-cloud-native-associate-kcna/), checked 2026-10-10.
